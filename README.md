# 番茄钟（本地桌面应用）

简约、护眼、清晰、干净的本地番茄钟。基于 Electron 构建，无边框小窗，数据全部保存在本机。

## 如何启动

**首次使用**（只需一次）：

```bash
cd 文件夹
npm install
```

**以后每次启动**：直接双击 `启动番茄钟.bat`（或运行 `npm start`）。

> 依赖安装使用国内镜像加速（npmmirror），无需科学上网。
> 若双击 bat 无效，用终端进入该目录执行 `npm start` 即可（bat 已改为纯 ASCII 内容，规避编码问题）。

## 功能说明

| 功能       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| 北京时间   | 固定使用 Asia/Shanghai 时区，显示 时:分:秒                   |
| 学习时长   | 可手动输入或点按 −/＋ 调节小时、分钟；结束自动切换到休息     |
| 休息时长   | 同上；结束自动切换回学习，循环进行                           |
| 累计时长   | 今日累计 = 今天所有「记录」的学习时间之和                    |
| 记录       | 点击把「本次学习」时间写入本地 Excel 并计入今日累计，本次学习归零 |
| 历史记录   | 日历视图按月查看每天的学习时间，可翻页，含本月合计           |
| 今日待办   | 手动添加，最多 4 项，复选框勾选完成；每天 6:00 自动清除      |
| 设置       | 北京时间 / 学习倒计时 / 休息倒计时字体大小；提示音音量       |
| 提示音     | 学习结束播放 A 音频，休息结束播放 B 音频，本地选择文件       |
| 开机自启动 | 设置面板里的开关，开启后登录 Windows 自动启动（写当前用户注册表，无需管理员权限） |

## 数据保存位置

- 设置、待办、累计时长：Electron userData（本机，不联网）`C:\Users\xbox\AppData\Roaming\tomato-clock\`
- 窗口位置/大小/置顶/锁定：同一目录下的 `window-state.json`
